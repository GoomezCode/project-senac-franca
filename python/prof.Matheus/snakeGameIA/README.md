# 🐍 Snake Game PRO

Um jogo da cobrinha moderno feito em **HTML, CSS e JavaScript puro**, com visual estilo arcade neon e diversas funcionalidades avançadas.

---

## 🎮 Demonstração

Este projeto inclui:

- Menu inicial estilizado
- Sistema de configurações
- Controles customizáveis
- Sistema de pause
- Score e recorde (high score)
- Visual com efeitos neon e animações

---

## 🧠 Como o jogo funciona

O jogo utiliza o elemento `<canvas>` do HTML para renderizar gráficos 2D.

A cada ciclo:
1. A direção da cobra é atualizada
2. A posição da cabeça é calculada
3. Colisões são verificadas
4. A cobra cresce ou se move
5. A tela é redesenhada

---

## 📁 Estrutura

### HTML
Define a estrutura das telas do jogo:

- Menu
- Configurações
- Jogo
- Pause
- Game Over

### CSS
Responsável pelo estilo:

- Tema neon/arcade
- Animações
- Efeitos visuais (glow, pulse, scanline)

### JavaScript
Controla toda a lógica:

- Movimento
- Colisão
- Pontuação
- Inputs
